# Directories and lists

Check each list's contribution rules first: some want a minimum number of stars, or an app that's been around
for a while. If one does, come back after the launch posts.

## AlternativeTo (alternativeto.net)

- **Name:** YouputDesk
- **Description:** Free, open-source desktop app for YouTube Music on Windows. Runs the real YouTube Music (Premium
  works) and adds a 10-band equalizer with a limiter, synced lyrics, themes, a tray mini player, global hotkeys,
  ad alerts and Discord status. No accounts or analytics.
- **Alternative to:** YouTube Music, YouTube Music Desktop App (th-ch)
- **Platforms:** Windows
- **License:** Free, Open Source (MIT)
- **Tags:** music-player, youtube-music, equalizer, lyrics, discord-integration, portable

## Scoop Extras (later)

Once the app has some users, open a PR at ScoopInstaller/Extras with `bucket/youputdesk.json` from
roderio/scoop-bucket, so people can run `scoop install extras/youputdesk`. Extras expects apps that are
reasonably well known, so wait until there's real usage.

## Download sites

Softpedia, MajorGeeks and Uptodown accept software submissions through forms on their sites. Use the AlternativeTo
description, the social card and the screenshots. They mirror the installer, which is fine; ask them to link to the
GitHub releases page for updates.
